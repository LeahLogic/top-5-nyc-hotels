
# Top 5 Hotels in New York 

A luxury hotel collection built with React, featuring five iconic hotels in New York City.

The website combines elegant design, beautiful hotel photography, and interactive features to create a sophisticated browsing experience.

## Features

- Explore five luxury hotels in New York City
- View hotel photos and descriptions
- Expand and collapse descriptions with Read More / Read Less
- Remove hotels from the collection
- Automatically update the number of remaining hotels
- Visit official hotel websites
- Responsive layout for desktop and mobile devices

## Technologies Used

- React
- JavaScript (ES6)
- HTML5
- CSS3
- Vite
- Google Fonts

## React Concepts

- useState
- Array.map()
- Array.filter()
- Array.includes()
- Conditional rendering
- Event handling
- Props and data destructuring
